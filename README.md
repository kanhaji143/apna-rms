# APNA Computer RMS (अपना कंप्यूटर रिकॉर्ड मैनेजमेंट सॉफ्टवेयर)
> **100% Offline Admission & Payment Record Management System for Coaching Institutes**  
> *कॉलिंग टीम, फ्रंट-डेस्क एडमिशन, कोर्स एक्टिवेशन, अकाउंटिंग व टैक्स मिलान सॉफ्टवेयर*

---

## 🌟 प्रमुख विशेषताएं (Key Features)

1. **100% सुरक्षित एवं ऑफलाइन (100% Offline First):**
   - इंटरनेट के बिना लोकल मशीन पर तुरंत काम करता है।
   - यूजर-चॉइस डेटा डायरेक्टरी (D: या E: ड्राइव) — जबरन C: ड्राइव में डेटा नहीं जाता।
   - SQLite डेटाबेस और ऑटो-ऑप्टिमाइज्ड स्क्रीनशॉट्स (100–150 KB).

2. **कॉलिंग (Online) एवं वॉक-इन (Cash) एडमिशन:**
   - छात्र विवरण, बहु-कोर्स (Multi-Course) चेकबॉक्स।
   - यूपीआई यूटीआर व पेमेंट स्क्रीनशॉट अटैचमेंट।
   - पुराने छात्र के लिए रियायत (Concession / Loyalty Discount) ऑटो-कैलकुलेटर।
   - डुप्लिकेट फोन/ईमेल व समान UTR पर स्मार्ट सॉफ्ट-वॉर्निंग।

3. **कोर्स एक्टिवेशन कतार (Activation Queue):**
   - 🚩 रेड-फ्लैग पेंडिंग अलर्ट्स।
   - 1-क्लिक 'Mark as Activated' विथ तारीख व समय की सटीक टाइमस्टैम्पिंग।
   - बल्क एक्सेल एक्टिवेशन सिंक।

4. **शाम की दैनिक बैकअप ईमेल (EOD Daily Report):**
   - स्टाफ शाम को 1-क्लिक करेगा और आज की पूरी Excel शीट व स्क्रीनशॉट्स की Zip एडमिन के ईमेल पर ऑटो-सेंड हो जाएगी।
   - ऐप बंद करते समय सुरक्षा रिमाइंडर।

5. **व्हाइट-लेबल एवं री-सेल तैयार (Commercial Ready):**
   - लोगो, इंस्टिट्यूट का नाम, पता, सोशल मीडिया लिंक्स सेटिंग्स से बदलने योग्य।
   - अन्य कोचिंग या स्कूलों को अपने ब्रांड पर बेचने के लिए पूर्णतः तैयार।

6. **टीचर टाइम-टेबल एवं 1-क्लिक व्हाट्सएप ब्रॉडकास्ट:**
   - वीकली क्लास शेड्यूल, अवकाश (Leave) व सब्स्टीट्यूट टीचर अलॉटमेंट।
   - 💬 1-क्लिक में आज की सभी कक्षाओं का शेड्यूल कोचिंग के फैकल्टी व्हाट्सएप ग्रुप में ब्रॉडकास्ट करें।

7. **स्टाफ व फैकल्टी डायरेक्टरी (Advance & Salary Ledger):**
   - टीचर्स, डायरेक्टर्स और सब-स्टाफ की पूरी डायरेक्टरी।
   - महीने के बीच में एडवांस देने, ऑटो-एडजस्ट करने व 1 महीने बाद का पिछला वेतन देने का पूरा लेजर हिसाब।
   - ऑटो-एक्सपेंस सिंक ताकि संस्थान का नेट प्रॉफिट हमेशा 100% सटीक रहे।

8. **⚡ स्मार्ट मल्टी-पीसी ऑटो-डेटा मर्ज (Multi-PC Auto-Merge):**
   - LAN / Wi-Fi नेटवर्क के बिना भी विभिन्न कंप्यूटरों (PC-1, PC-2, PC-3) की दैनिक बैकअप फाइलों (.db / .zip) को ओनर 1-क्लिक में बिना डुप्लिकेट के मास्टर डेटा में मर्ज कर सकता है।

9. **🎮 1-क्लिक लाइव प्रेजेंटेशन डेमो मोड:**
   - लॉगिन स्क्रीन पर `1-क्लिक लाइव डेमो` बटन दबाते ही 10 सैंपल छात्र, ₹69,000 कलेक्शन और पूरे P&L ग्राफ के साथ क्लाइंट को तुरंत डेमो दिखाएं।
   - हेडर पर `[ 🔄 रीसेट डेमो डेटा ]` बटन से कभी भी डेमो डेटा फ्रेश करें।

10. **📖 तैयार ट्रेनिंग मैनुअल व सेल्स पिच गाइड:**
   - `dist/APNA_Computer_RMS_Training_Manual.pdf` — क्लाइंट संस्थान के लिए 6-पेज का संपूर्ण ऑपरेटिंग मैनुअल।
   - `dist/APNA_Computer_RMS_Sales_Pitch_Guide.pdf` — 5-मिनट में सॉफ्टवेयर सेल करने की सीक्रेट पिच व ऑब्जेक्शन हैंडलिंग गाइड।

11. **AI / LLM & टैक्स रेडी एक्सपोर्ट:**
   - 1-क्लिक में साफ-सुथरी Excel (.xlsx) रिपोर्ट, जिसे सीधे ChatGPT या Gemini में अपलोड करके वित्तीय विश्लेषण किया जा सकता है।
   - पुराने छात्रों का बल्क एक्सेल डेटा इम्पोर्ट।

## 🛠️ सिस्टम सेटअप व रन कैसे करें (Quick Start)

### 1. आवश्यकताएं (Requirements):
- Python 3.10+
- आवश्यक लाइब्रेरीज इंस्टॉल करें:
```bash
python -m pip install -r requirements.txt
```

### 2. सॉफ्टवेयर शुरू करें (Run Application):
```bash
python app.py
```

### 3. पहली बार रन करने पर (First-Run Wizard):
1. अपना पसंदीदा स्टोरेज फ़ोल्डर चुनें (उदा: `D:\APNA_Institute_Data`).
2. एडमिन खाता और पासवर्ड बनाएं।
3. **Master Recovery Key** सुरक्षित लिखकर रखें (पासवर्ड भूलने पर रिकवरी के लिए)।
4. 'Complete Setup' दबाते ही लॉगिन स्क्रीन खुल जाएगी।

## 📦 स्टैंडअलोन Windows EXE कैसे बनाएं (Create Installer)

क्लाइंट के कंप्यूटर पर बिना पाइथन के चलाने के लिए एक सिंगल `.exe` फाइल बनाएं:
```bash
python -m pip install pyinstaller
python build_installer.py
```
बिल्ड पूरा होने पर `dist/APNA_Computer_RMS.exe` फाइल तैयार मिल जाएगी जिसे पेनड्राइव में डालकर किसी भी Windows PC पर चलाया जा सकता है।
